# Agent Skill Store Specifications

These specifications describe the public formats Agent Skill Store publishes and consumes.

These documents describe the formats and trust boundaries implemented by the v0.2.0 server, client, and CLI.

| Spec | Purpose |
|------|---------|
| [Skill Packages](skills.md) | AgentSkills.io-compatible skill authoring and Agent Skill Store artifact projection. |
| [Sub-Agent Packages](subagents.md) | Versioned sub-agent definition and publication model. |
| [Native Manifest](native-manifest.md) | Linked non-RFC sync feed for skills, sub-agents, and future artifact types. |
| [Security And Trust Model](security.md) | Trust boundaries, authentication, digest verification, and sync safety for native sync. |
