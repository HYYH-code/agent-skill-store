# Code of Conduct

## Our Standard

Contributors must communicate respectfully, focus criticism on the work, accept good-faith feedback, and avoid harassment, discrimination, threats, or disclosure of private information.

## Scope

This standard applies in repository discussions, issues, pull requests, reviews, and project-related community spaces.

## Enforcement

Report unacceptable behavior privately to the repository maintainers. Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when necessary to protect the project community.

Enforcement decisions should be proportional, documented privately, and applied consistently.
