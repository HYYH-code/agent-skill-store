# Upstream Provenance

Agent Skill Store is derived from an Apache-2.0 licensed upstream registry project originally developed by Petabridge, LLC.

The open-source rewrite preserves applicable source copyright headers, the Apache-2.0 license, and attribution notices. The public repository uses a new project name, package names, command name, configuration namespace, documentation, and independently created brand assets.

No original private repository history or internal brand assets are included in the public repository.

Upstream-derived behavior includes the core Skill registry, versioned artifacts, discovery feeds, SQLite persistence, content-addressed blobs, typed client foundations, and portions of the CLI implementation.
